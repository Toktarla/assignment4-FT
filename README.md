# Assignment 4 - Security, Resilience and Intrusion Tolerance

Synthetic research-server incident for Astana IT University, Fault Tolerance, 2026-2027.

The timeline, addresses and scores are educational data. They are not from real AITU systems.

## Run

```bash
python3 -m src
```

Prints Parts A-E and writes `results/tables.md`, `results/simulation.json` and `diagrams/architecture.svg`.

## Layout

- `data/incident.json` — event timeline and AI scores from the brief
- `src/` — classification, risk matrix, architecture simulation, recovery, anomaly check
